║           MONGODB ATLAS PASSWORD SETUP - QUICK GUIDE             ║
╚══════════════════════════════════════════════════════════════════╝

🔑 YOU NEED TO SET YOUR MONGODB PASSWORD BEFORE RUNNING THE APP!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

METHOD 1: Direct Replacement (Simplest)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open the .env file in this directory
2. Find this line:
   MONGODB_URI=mongodb+srv://cyberbulling:<db_password>@cluster0...

3. Replace <db_password> with your actual MongoDB Atlas password
   Example:
   MONGODB_URI=mongodb+srv://cyberbulling:MySecurePass123@cluster0...

4. Save the file

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

METHOD 2: Separate Variable (More Secure)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open the .env file
2. Add a new line anywhere:
   MONGODB_PASSWORD=YourActualPassword123

3. The app will automatically replace <db_password> with this value
4. Save the file

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📍 WHERE TO FIND YOUR MONGODB PASSWORD
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to https://cloud.mongodb.com/
2. Login to your account
3. Click "Database Access" in the left sidebar
4. Find the user "cyberbulling"
5. If you forgot the password:
   - Click "Edit" next to the user
   - Click "Edit Password"
   - Set a new password
   - Copy it and use it in the .env file

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚠️  IMPORTANT SECURITY NOTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✓ Never share your .env file
✓ Never commit .env to Git/GitHub
✓ Use a strong password (letters, numbers, symbols)
✓ Whitelist your IP in MongoDB Atlas Network Access

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🧪 TESTING THE CONNECTION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

After setting the password:

1. Install dependencies:
   pip install -r requirements.txt

2. Run the app:
   python app.py

3. Look for this message:
   ✅ MongoDB connected successfully to database: cyberguard

   If you see this instead:
   ⚠️  WARNING: MONGODB_URI not set...
   → Check your .env file

   If you see this:
   ❌ MongoDB connection failed...
   → Check your password is correct
   → Check your IP is whitelisted in MongoDB Atlas

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✨ WHAT HAPPENS IF MONGODB FAILS?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Don't worry! The app will:
- Print a warning message
- Fall back to in-memory storage
- Continue working normally
- BUT: User data will be lost when you restart the app

So it's best to fix the MongoDB connection for persistent storage!
